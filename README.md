# TejBank
Tujbank — API de sistema bancário (projeto de estudo)

O que é: Uma API REST em Java 21 + Spring Boot 4 que simula operações básicas de um banco digital: cadastro de clientes, autenticação, e (em desenvolvimento) contas e movimentações financeiras.

Stack: Java 21, Spring Boot 4, Spring Data JPA, Spring Security, MySQL, Maven.
